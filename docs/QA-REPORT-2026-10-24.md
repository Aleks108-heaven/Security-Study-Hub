# QA report: Security Testing Study Hub 1.1.0

Date: 24 October 2026. Final status: **PARTIALLY VERIFIED**.

## 1. Executive summary

The app was reworked into an assessment tool (evidence-based mastery, stratified exam draw, progress report), given a hash-based CSP, and extended with Ukrainian, Polish, Spanish and German. All automated checks pass: dataset validator 0 errors and 0 warnings, 20 of 20 validator negative tests, translation validator 0 errors, 180 of 180 end-to-end checks, 68 of 68 language checks, 28 of 28 feature checks, 0 axe violations in four English configurations, and no colour pair below the contrast limit.

The status is not PASS because the translations have no native-speaker review, and nothing was run on real devices, in Safari or Firefox, or with a screen reader.

## 2. Mode and scope

Mode C (live app and source). The live app was a headless Chromium driven by Playwright 1.63.0 on `file://` pages; the source was read and checked statically. Only local files were tested; no third-party system and no production host was touched. Test data was synthetic progress documents.

In scope: quiz, flashcards, exam simulator, report, language switching, import/export, layout, CSP, the dataset and its translations. Out of scope: the optional claude.ai sync and downloads (they need the artifact host), GitHub Pages and CI (the workflows have not run yet).

## 5. Defects found and fixed during this work

| ID | Severity | Finding | Impact | Status |
| --- | --- | --- | --- | --- |
| D1 | Medium | At 320 px in Spanish the Labs screen overflowed by 22 px: `.tag` did not wrap and `.seg` buttons did not shrink | Horizontal scrolling on small phones for long translated labels | Fixed in `src/style.css`; i18n suite 67 to 68 of 68 |
| D2 | Low | A Latin letter inside the Ukrainian word "сертифіковані" (q-grc-06) | Odd text, can break search | Found by the mixed-script check; fixed |
| D3 | Low | Typos "скануютьчи" (fc-tools-06) and "known-вадою" (q-process-03) in Ukrainian | Reads as a mistake | Fixed |
| D4 | Medium | q-ai-08 explanation was wrong | A learner could study a false statement | Fixed in the dataset and in `questions.md` |
| D5 | Medium | Mastery averaged every attempt, so repeating one question inflated or sank a topic; a random draw could clump in one topic | Misleading readiness figures for a tool meant to check knowledge | Fixed (evidence rule, stratified draw); covered by `test/features.cjs` |

Regression tests: D1 by `test/i18n.cjs` (320 px in every language), D5 by `test/features.cjs`. D2 and D3 are covered by `validate_i18n.py` only for the mixed-script case; the typos have no automated check.

## 6. Security findings

Confirmed: none open. Potential: the page still loads Google Fonts (a third-party request that reveals the visit to Google); this was kept on purpose and is allowed by the CSP, and if it is blocked the app falls back to system fonts. Could not perform: any penetration test of the claude.ai host or of GitHub Pages; header-based protections (`frame-ancestors`, HSTS) cannot be set from a static page and depend on the host.

## 7. Language-specific findings (JavaScript)

No `eval`, `innerHTML`, inline handlers or string timers in the source (enforced at build time). Imported progress is validated against a schema in code and rejected with a reason; the language setting is validated against a fixed list. Untrusted translation overlays are text-only and cannot change structure.

## 8. Recommendations

1. Have a native-speaking security tester review the questions and modules in each language (highest value, unknown effort per language). Until then keep the notice in Settings.
2. Run `node test/shots.cjs` with a non-English locale as well, and test in Firefox and Safari. Trade-off: more configurations means a longer run.
3. Consider self-hosting the fonts to drop the last third-party request. Trade-off: about 100 to 300 KB more in the page, and a licence check.
4. Bump the dataset version when the content changes (for example q-ai-08), and regenerate `SHA256SUMS.txt`.
5. After the first push, check that both workflows run green and enable Pages in the repository settings.
6. Add more questions: with 126, a 40-question mock repeats after about three tries, which limits its value as a fresh measure.
